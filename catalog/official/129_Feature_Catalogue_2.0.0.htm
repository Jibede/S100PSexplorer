    ~ U ~

    Under Keel Clearance Purpose (underKeelClearancePurpose)

    Type: enumeration
    Definition: The relevant phase of a UKC passage plan.

    LabelCodeDefinition
    Pre Plan1An indicative UKC plan that identifies potential sailing windows for a nominated vessel draught; days, weeks or months prior to the planned passage through the UKCM region.
    Actual Plan2A detailed Under Keel Clearance plan that identifies sailing windows and no-go areas, integrating live weather data, hours or days prior to transiting the Under Keel Clearance Management region.
    Actual Update3A near real-time, detailed, Under Keel Clearance plan that identifies sailing windows and no-go areas, using live weather, vessel position and traffic data, while the vessel is transiting the Under Keel Clearance Management region.

    Used by:

    • UnderKeelClearancePlan

    Under Keel Clearance Calculation Requested (underKeelClearanceCalculationRequested)

    Type: enumeration
    Definition: Indication of the aim of the UKC plan: To find the maximum safe vessel draught for transiting the UKCM region, or to find sailing windows for a nominated vessel draught.

    LabelCodeDefinition
    Time Window1The available time window(s) for a given draught.
    Maximum Draught2The maximum draught for a given time window.

    Used by:

    • UnderKeelClearancePlan
