Feature Details

NAVWARN Part (NavwarnPart )

Definition: Navigational warning information that may be geo-located.

Primitive: point, curve, surface

Attributes:

  • Restriction (restriction) [0,1]
     permitted values : 7, 8, 14, 25, 27
  • Fixed Date Range (fixedDateRange) [0,*]
  • Warning Information (warningInformation) [1,1]
  • Feature Name (featureName) [0,*]
  • Feature Reference (featureReference) [0,*]

Can be associated with feature(s):

  • NavwarnAreaAffected via areaAffected as affects role [0,*]
  • TextPlacement via TextAssociation as thePositionProvider role [0,*]

Can be associated with information(s):

  • NavwarnPreamble via navwarnPreambleContent as header role [1,1]

NAVWARN Area Affected (NavwarnAreaAffected )

Definition: An area affected by some event marked by a navigational warning.

Primitive: point, curve, surface

Can be associated with feature(s):
